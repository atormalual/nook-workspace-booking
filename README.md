# 🏢 Nook — Workspace Booking System

A web-based workspace booking application designed to help users explore available workspaces, filter rooms based on capacity, and manage workspace reservations.

Nook is an independent software development project focused on applying JavaScript programming, frontend development, data management, and software design principles to a practical booking system.

## 🚀 Features

### Implemented Features
- **Workspace Listings:** Display available workspaces with information about room names, capacity, and availability.
- **Capacity Filtering:** Filter workspaces based on minimum seating capacity.
- **Booking Interactions:** Manage workspace booking states through interactive JavaScript functionality.
- **Local Storage:** Persist workspace availability and booking-related information across browser sessions.
- **Dynamic Rendering:** Update workspace listings using JavaScript and DOM manipulation.

### Planned Improvements
- User registration and authentication.
- Backend database integration.
- Date and time-based reservations.
- Improved booking validation and conflict detection.
- Enhanced user interface and responsive design.

## 💻 How to Run

1. Clone the repository or download the project files.
2. Open the `frontend` folder.
3. Open `index.html` in a web browser.
4. Navigate to the workspace listings page to explore the application.

No additional dependencies or installation are required for the current frontend implementation.
